# IEDB Streamlit application

An interactive Streamlit app was preserved in the project Drive archive. It contains `app.py`, `requirements.txt`, and an app README.

- Drive folder: `https://drive.google.com/drive/folders/1RZa4ruVhqgqPhurbDz0TeTrE97-BHp8O`
- `app.py`: `https://drive.google.com/file/d/1fAcveyPdTKvvPBKKp6RCAYCZ5vihJD0l/view`
- App README: `https://drive.google.com/file/d/180rtghm77IALFrYeOuypnFs4gwD48hhp/view`
- Requirements: `https://drive.google.com/file/d/1uuEf2m6eld8xvMDSOEv5Qm4XHSyepeKw/view`

The app is an exploratory user interface and is not the authoritative implementation of the frozen splits, corrected metrics, strict temporal sensitivity, or manuscript figures. Those are produced by the repository scripts and notebooks. Before deployment, its input paths and model-loading behavior should be reconciled with the current repository layout.
