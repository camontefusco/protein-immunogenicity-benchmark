# Bayer Role Signal Map

This project should make the following job-ad signals visible.

## Sequence-to-Function Models

Portfolio evidence:

- supervised peptide immunogenicity prediction
- classical descriptors versus learned protein embeddings
- performance stratified by biological metadata

## Protein Language Models

Portfolio evidence:

- frozen ESM2 or ProtT5 embeddings
- documented embedding extraction workflow
- comparison against interpretable non-PLM features

## Biomolecular Workflow Judgment

Portfolio evidence:

- explicit dataset curation notes
- assay and label definitions
- leakage checks for near-duplicate sequences
- error analysis grounded in peptide biology

## Scientific Rigor

Portfolio evidence:

- cross-validation design
- calibration metrics
- uncertainty discussion
- transparent limitations

## Collaborative Software Engineering

Portfolio evidence:

- package layout under `src/`
- tests
- command-line entry points
- config files
- reproducible README instructions

## Communication

Portfolio evidence:

- short report explaining what worked, what failed, and why
- figures that a biologist, chemist, or ML scientist can understand
- discussion of tradeoffs between interpretability, performance, and biological validity
